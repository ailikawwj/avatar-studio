# 同画头像工坊

这是一个在本地运行的 Q 版头像智能体。用户先描述需求，豆包语言模型整理成绘图指令并调用 Seedream；生成后可以通过第二个对话框继续提出修改。

## 使用方法

1. 在火山方舟创建 API 密钥，并分别开通豆包语言模型和 Seedream。
2. 在 PowerShell 中进入本文件夹。
3. 临时设置密钥：`$env:SEEDREAM_API_KEY="你的密钥"`
4. 设置语言模型 ID：`$env:DOUBAO_LLM_MODEL="控制台中的模型ID"`
5. 启动：`npm start`
6. 电脑浏览器打开 `http://127.0.0.1:4184`。手机与电脑连接同一 Wi-Fi 后，使用电脑的局域网 IP 加端口 `4184` 访问。

密钥只设置在本机环境变量中，不要写进网页，也不要发给别人。
